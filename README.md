# Цитаты

Небольшое веб-приложение с 20 цитатами и интеграцией Telegram Web App.

## Возможности

- Просмотр цитат и категорий.
- Переключение кнопкой, свайпом и стрелками клавиатуры.
- Отметки «Нравится» в пределах открытой страницы.
- Передача цитаты через Telegram или копирование в браузере при поддержке соответствующих возможностей.

При загрузке порядок цитат перемешивается. Избранное хранится в памяти страницы и сбрасывается при перезагрузке.

## Структура

| Файл | Назначение |
|---|---|
| [index.html](index.html) | Интерфейс, стили, список цитат и клиентская логика |
| [server.js](server.js) | HTTP-сервер на встроенных модулях Node.js |

## Локальный запуск

Нужны Git и установленный Node.js.

```sh
git clone https://github.com/Matvey1983/quotes-app.git
cd quotes-app
node server.js
```

Откройте [http://localhost:3001](http://localhost:3001). Для остановки сервера нажмите Ctrl+C.

Сервер использует только встроенные модули Node.js; установка npm-пакетов не требуется. Telegram SDK загружается из сети.

## Ручная проверка

1. Открыть страницу: цитата, автор, категория и счётчик должны отображаться.
2. Переключить цитаты кнопкой, стрелками клавиатуры и свайпом на сенсорном устройстве.
3. Поставить отметку «Нравится», перейти к другой цитате и вернуться.
4. Проверить действие «Поделиться» в браузере и отдельно внутри Telegram.

Автоматических тестов в репозитории пока нет. Работа интеграции Telegram проверяется отдельно в соответствующем окружении.
